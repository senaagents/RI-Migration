# SAP Migration Control

This folder is the operating record for the LLM SAP migration.

- `sap-migration-plan.md`: phase plan and gating rules
- `progress-log.md`: dated work log and command outcomes
- `reconciliation-checklist.md`: migration validation checklist
- `sap-source-inventory.md`: source table scope and current counts
- `sap-lean-staging-policy.md`: default policy for keeping only migration-relevant SAP raw/support data
- `audits/`: setup/master audits before import
- `exceptions/`: machine-generated exception registers from audits
