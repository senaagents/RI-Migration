# SAP HANA Column Case Sensitivity

## Trigger

The first generated profile query used unquoted SAP B1 column names such as `DocDate`.

HANA resolved the identifier as uppercase `DOCDATE`, and SAP B1 tables rejected it with an invalid-column error.

## Migration Impact

Every SAP extraction query must quote SAP B1 identifiers exactly. This matters for:

- Header date columns: `DocDate`, `RefDate`, `PostDate`
- Header keys: `DocEntry`, `TransId`
- Line fields: `LineNum`, `ItemCode`, `AcctCode`, `WhsCode`

Unquoted identifiers can make a correct table look broken, or worse, make a query accidentally target the wrong field if a case-insensitive assumption leaks into generated SQL.

## Rule

All migration SQL generated by `sap-db-pipeline` must quote SAP schema, table, and column identifiers.

## Verification

After quoting columns, the profile command succeeded for the full `2025-04-01` through `2026-04-25` window across the planned SAP document families.
